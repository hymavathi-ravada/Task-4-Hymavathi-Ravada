# Data Visualization

# Project Overview
This project presents an interactive Sales Analytics Dashboard built using Python and Plotly. The dashboard visualizes key business metrics such as revenue, sales trends, order status distribution, and referral source performance, enabling data-driven decision-making through interactive charts and insights.

# Objective
Create an interactive dashboard for sales analysis.
Visualize key business metrics and trends.
Monitor product, revenue, and order performance.
Generate actionable business insights from data.

# Technologies Used
Python
Pandas
Plotly

# Visualizations Created
1. Revenue by Product (Bar Chart)
Displays revenue generated by each product category.

2. Monthly Revenue Trend (Line Chart)
Shows sales performance over time and helps identify trends and seasonality.

3. Order Status Distribution (Pie Chart)
Visualizes the distribution of order statuses such as completed, pending, or cancelled.

4. Revenue by Referral Source (Bar Chart)
Compares revenue generated through different marketing channels.

# Key Features
KPI Summary (Revenue, Orders, Average Order Value)
Revenue by Product Analysis
Monthly Revenue Trend Visualization
Order Status Distribution Analysis
Referral Source Performance Tracking
Interactive Dashboard using Plotly
Automated Business Insights Generation

# output
The dashboard visualizes sales performance, revenue trends, and product insights through interactive charts. It helps users quickly understand business performance and make data-driven decisions.
